# 🌈 RENKLİ RÜYA İZİN BELGESİ ÜRETİCİ

## Resmi Açıklama (Çok Resmi)

Bu yazılım, **Evrenin Rüya İşleri Genel Müdürlüğü** (ERİGM) tarafından onaylanmış, bilimsel olarak %0.0001 doğruluk oranına sahip, tamamen gereksiz ama hayati önem taşıyan bir araçtır.

### Ne İşe Yarar?

Hayatınızda bir kez bile renkli rüya gördüyseniz, yasadışı rüya görme suçundan dolayı yargılanma riskiniz vardır. Bu yazılım sayesinde:

- Resmi olmayan ama **çok resmi görünen** izin belgesi alabilirsiniz
- Belgeyi rüyada polise gösterebilirsiniz (işe yaramaz ama moral verir)
- Kuantum rüya olasılığı hesaplanır (sonuç her zaman "şüpheli" çıkar)
- Belgeye damga, imza ve hayali mühür basılır

### Kurulum

```bash
# Sadece Python 3 yeter. Başka bir şey yüklemeye gerek yok çünkü evren zaten yeterince karmaşık.
python ruya_izin.py
```

### Kullanım

Program size adınızı soracak, sonra 7 saniye düşünecek (bilimsel hesaplama süresi), ardından size resmi bir belge basacaktır.

### Uyarılar

- Bu belge hiçbir mahkemede geçerli değildir.
- Rüyada kullanırken uyanırsanız sorumluluk size aittir.
- Renk körü iseniz belge siyah-beyaz çıkar (kuantum etkisi).
- Programı salı günleri çalıştırmanız önerilir. Diğer günler belge "geçici" olarak işaretlenir.
